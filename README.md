# Riverside County Government v1.0.0

Public Next.js portal. No login is required.

## Environment
`DATABASE_URL` — use the same Neon database as RinCEN and the other County terminals.

## Features
- video hero beginning at approximately 2 seconds on every loop
- public announcements
- County Governance and agency directory
- optional contextual help, off by default
- public business transaction filing backed by the shared county tax ledger

The tax schedule is fictional and intended for the Riverside RP setting.
