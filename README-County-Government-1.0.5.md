# Riverside County Government v1.0.5

Die öffentliche Website wurde auf Deutsch umgestellt. Die offizielle Trust-Banner-Zeile
„An official website of the Riverside County Government. Here's how you know“
bleibt auf ausdrücklichen Wunsch in englischer Sprache.

Enthalten:
- deutsche Navigation, Seitenüberschriften, Formulare, Hinweise und Status-/Fehlermeldungen
- deutsche Steuer- und Einreichungshilfe
- feldspezifische deutsche (i)-Hilfetexte im Steuerformular
- deutsche API-Fehler für öffentliche Steuererklärungen
- HTML-Sprache `de`
- bestehender Filing-Access-Code-Schutz aus v1.0.4 bleibt unverändert

Keine neuen Environment Variables und keine manuelle SQL-Migration erforderlich.
